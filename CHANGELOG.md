# Changelog

## 0.1.0 — Alpha preparation

- Body grids, expansion boards, saved placement actions, surgery and hot swapping.
- Shared power, fuel generation, charging stations and automatic supply policies.
- Passive, toggle, one-shot and reactive abilities with cast actions and caravan rules.
- Implant damage, contamination, sterilization, burden and configurable residual faults.
- Research tab, module dependencies, modes, exclusions and host compatibility tags.
- Extensible workers, custom events, per-instance saved ability data and resource providers.
- Repository build, generated-data validation, rule regressions and release packaging.

This version is being prepared; this changelog does not imply a Steam Workshop publication.
