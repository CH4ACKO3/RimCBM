# RimCBM 0.1.0 — Alpha

Initial framework preview: body grids and expansion, surgery and hot swapping, shared energy, fuel and charging, four ability types, damage and faults, burden, research, dependencies, modes and extension workers.

Includes prototype modules. Content progression and balance remain in development. Requires RimWorld 1.6 and Harmony; English and Simplified Chinese are supported. This file is release preparation, not confirmation of a Steam upload.
