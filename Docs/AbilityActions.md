# 能力动作、效果与地图外规则

地图内的主动能力统一从 `CBMCasting.Queue` 下达。Gizmo、右键目标菜单和能力配置入口都使用同一路径。`CBMAbilities.Activate` 是最终结算接口，也供反应式能力调用，扩展 UI 不应直接调用它来绕过动作。

## 动作流程

寻找可达且满足射程、视线的位置 → 移动 → 准备（`warmupTicks`，默认 60）→ 复查 → 一次扣能、设置冷却、执行效果。目标移动导致准备期间脱离射程或视线时取消；不自动无限追击。没有合法位置时菜单不可用。远距离寻位搜索半径上限 56 格，当前位置本来合法时不受该搜索限制。

任务的 `source` 引用具体植入体，`dutyTag` 保存能力字符串 ID，随原版任务一起存档，不依赖 XML 列表索引。反复点击相同的待释放能力不会建立重复任务；新的主动能力命令遵循原版指令规则，会中断当前任务。准备期不预扣能，执行时重新检查余额，所以其他能力耗尽电量会导致此次释放失败。取消、目标死亡/离图、阵营不匹配、宿主失能、植入体移除/损坏停机、依赖失效、EMP 或模式锁定均不会产生该次效果或冷却。

投射物发射以后已经完成支付；途中目标改变、掩体拦截或未造成伤害不会退费。反应式能力即时响应，受同一目标、效果、冷却、能源及储备规则约束，并有防递归保护。

## 可组合效果

`CBMAbilitySpec.effects` 按顺序执行；释放前每项效果必须可以应用。保留原有 `healAmount` 和 `damageAmount` 字段以兼容旧定义，旧字段先执行，随后执行 effects，因此不要将同一效果重复声明。

| kind | 参数及行为 |
| --- | --- |
| Damage | `damageDef`, `amount`, `armorPenetration`；调用原版伤害链，保留护甲、部位选择与受伤回调。直接命中，无额外命中检定。 |
| Projectile | `projectile` 引用原版/模组 Projectile ThingDef；原版飞行、碰撞、命中及护甲结算。伤害来自投射物 Def，`amount` 不覆盖其伤害。 |
| Heal | `amount` 为共享伤口严重度预算；优先流血伤口，不治永久损伤、不再生缺失部位，也不隐式恢复失血。 |
| Tend | `quality` 包扎质量，使用原版 Tended；处理当前可处理伤口/疾病，不直接删除它们，不消耗药品（成本由能力定义）。 |
| AddHediff | `hediff`, `amount`；增加指定全身状态严重度，若不存在则建立；期限由该 Hediff 的原版 comps 控制。 |
| ReduceHediff | `hediff`, `amount`；在同类状态间共享削减预算，到零才移除。例如失血需要明确配置这一效果。 |

数值效果乘植入体耐久和当前 tag/模式效果系数。Projectile 的原版弹丸数值保持 Def 定义。能力伤害不会绕过已有的植入体受击、反应能力与损坏系统。

新增自定义效果继承 `CBMEffectWorker`，实现无副作用 `CanApply` 和提交效果 `Apply`，用 `workerClass` 注册。访问地图的 worker 必须覆写 `MapOnly => true`。效果验证不应扣能或修改世界，提交不能再次收取能力能源。effects 属于单次/反应式；被动和切换能力使用现有持续能耗、供电租期与 statOffsets，禁止定义一次性 effects，以免产生没有触发途径的配置。

```xml
<effects>
  <li><kind>Heal</kind><amount>4</amount></li>
  <li><kind>Tend</kind><quality>0.6</quality></li>
</effects>
```

## 地图外统一规则

| 宿主位置/状态 | 运行规则 |
| --- | --- |
| 地图内且存活、未休眠 | 原有供能、能力、故障运行；主动释放需完成动作。 |
| 商队内且存活、未休眠 | 储能、燃料发电、代谢供能、持续耗能、自身支持能力、被动属性及残留故障继续每 60 tick 运行。自身单次支持能力直接结算，无地图动作；反应式照常检测。 |
| 休眠、容器中运输、未活动的世界 pawn | 暂停供能、持续效果与故障结算；不补算遗漏 tick。 |
| 死亡/销毁 | 停止运行；物理重量及损坏残留仍由既有身体/物品机制处理。 |

`CBMRuntime.Running` 是共同宿主规则，`CBMRuntime.Allows` 加上能力场景规则。地图外只能以自己为目标，不可远程治疗同商队其他人、攻击、生成投射物或连接地图充电站。`mapOnly=true` 可进一步限制支持能力。运输中的物资不会被后台自动变成燃料；已有燃料在商队正常消耗，自动补给及充电站仍需地图上的实际任务。

冷却、临时效果和 EMP 使用游戏绝对 tick，到期会自然失效；暂停不是延长这些期限。故障恢复时最多尝试一次并重新安排下一次时间，不补发休眠期间所有故障。着火持续损坏只读取地图上真实附着的火；地图外放电故障仍可损伤宿主，但依赖地图的点火效果不会凭空生成地图火焰。

自定义残留故障继承 `CBMFaultWorker`，默认 `MapOnly=true`；只有明确不访问地图的 worker 才应覆写为 false。内置放电故障已允许商队运行。

扩展生命周期、事件与来源接口见 [ExtensionContracts.md](ExtensionContracts.md)。旧式主动能力也已通过适配层使用此动作流程，物品转换保留旧冷却。
